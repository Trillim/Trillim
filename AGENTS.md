# AGENTS.md

This project is named Trillim, and the goal is to build an open source platform that can efficiently run any model on any backend. We will achieve this by implementing:
- a high level descriptive language - TDL - to specify the model's architecture
- a compiler that converts a model computation graph from TDL to kernels that will be run
- a runtime that consumes a model directory and execution manifest generated by the compiler
- backends that abstract away hardware particulars
- kernel benchmarker to run representative loads through kernels and help the compiler decide the optimal kernels for different workload points on the hardware
- kernel library (in C/C++) to efficiently run inference for the TDL subgraph being targeted
- model pre/post processing to handle tasks like tokenization, predicted token to string conversion etc

The project will be in Python, except for the kernel library. This is a from scratch development, so we need not worry about backwards compatibility. Do NOT implement tests for now.

## V1 targets
- CPU only inference (AVX2 and ARM NEON w/o dotprod instruction)
- Single model inference on single backend
- Supported models
  - LLMs: Qwen3.5, Qwen3.8, Bonsai-2, BitNet-2B, Llama-bitnet, Qwen3, Zeta, Sweep, Gemma, Gpt-oss 20b and 120b
  - ASR: Whisper and Parakeet
  - TTS: PocketTTS
  - Image: Bonsai-Image, Flux2 image
- Package includes: TDL, Compiler, Runtime, Backend, KernelBench, Kernels, model pre+post processing
  - Usage becomes => preproc(input) - model runtime - postproc output
- Strict cancellation guarantees (cancellation = terminate current process gracefully ASAP)
- LoRA adapters (under submodel plan which is multiple model parts working together)
- Clean cache semantics for KV caching, recurrent state caching etc (scratch space for intermediate values is not included here)
